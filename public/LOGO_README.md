# Logo Placeholder

Place your GoGreen Club logo here as `logo.png`

The logo should be:
- PNG format
- Square dimensions (recommended: 512x512px or 1024x1024px)
- Transparent background (optional but recommended)

The logo will appear in:
- Navbar (top-left)
- Login page
- Signup page
- Welcome page
- Public landing page hero section
- Browser tab (favicon)
