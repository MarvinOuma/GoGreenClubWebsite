🔥 GET YOUR FIREBASE CONFIG NOW

1. Open: https://console.firebase.google.com/project/gogreen-club/settings/general

2. Scroll down to "Your apps" section

3. If you see a web app (</> icon), click it to view config
   If not, click "Add app" → Web (</>) → Register app

4. Copy these values from the config:

   apiKey: "..."
   authDomain: "..."
   projectId: "..."
   storageBucket: "..."
   messagingSenderId: "..."
   appId: "..."

5. Paste them into your .env file:

   VITE_FIREBASE_API_KEY=paste_apiKey_here
   VITE_FIREBASE_AUTH_DOMAIN=paste_authDomain_here
   VITE_FIREBASE_PROJECT_ID=gogreen-club
   VITE_FIREBASE_STORAGE_BUCKET=paste_storageBucket_here
   VITE_FIREBASE_MESSAGING_SENDER_ID=paste_messagingSenderId_here
   VITE_FIREBASE_APP_ID=paste_appId_here

6. Save the .env file

Then come back here!
