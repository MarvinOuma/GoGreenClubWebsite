✅ Full-Stack Web Application
   ├─ React 18 + Vite
   ├─ Tailwind CSS (custom GoGreen theme)
   ├─ React Router v6
   ├─ Firebase Backend (Auth, Firestore, Storage, Functions, Hosting)
   └─ Role-Based Access Control

✅ Three Complete Dashboards
   ├─ 🌐 Public Dashboard (Transparency Portal)
   ├─ 🎮 Member Dashboard (Impact Hub)
   └─ 🎛️  Admin Dashboard (Command Center)

✅ Authentication System
   ├─ Email/Password
   ├─ Google OAuth
   ├─ Auto role assignment (Cloud Function)
   └─ Custom claims for roles

✅ Blog CMS
   ├─ Create/Edit/Delete posts
   ├─ Image upload to Firebase Storage
   ├─ Publish/Unpublish toggle
   └─ Tag system

✅ Security
   ├─ Firestore security rules
   ├─ Storage security rules
   └─ Protected routes

🚀 QUICK START
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

1️⃣  Install Dependencies
    $ npm install
    $ cd functions && npm install && cd ..

2️⃣  Configure Environment
    $ cp .env.example .env
    # Edit .env with your Firebase credentials

3️⃣  Run Development Server
    $ npm run dev
    # Visit: http://localhost:5173

4️⃣  Deploy to Production
    $ npm run build
    $ firebase deploy
